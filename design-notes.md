# Design notes

Selected direction: a globe made from shopping, clothing, home, and nature icons, paired with the title “Shopping for a Better World.”

Visual tone: friendly, clear, and sustainability-focused, using green and blue on a light background.

The supplied campaign artwork has been resized to 400 × 400 pixels for the Solarpunk Magazine image-ad specification. The artwork is a PNG; no editable design source file was supplied.
